# CodeAlpha Image Gallery

A responsive image gallery created using HTML, CSS, and JavaScript as part of the CodeAlpha Frontend Development Internship.

## Features

- Responsive image gallery
- JavaScript lightbox
- Previous and next navigation
- Keyboard navigation
- Image hover effects
- Smooth transitions
- Category filters
- Mobile-friendly design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Categories

- Nature
- Animals
- Places

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Click an image to open the lightbox.
4. Use the navigation buttons to browse images.
